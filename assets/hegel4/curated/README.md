# hegel4 — Enzyklopädie der philosophischen Wissenschaften im Grundrisse (1830)

The third and final edition (1830) of Hegel's *Encyclopaedia of the
Philosophical Sciences in Outline*, following the text of the Gesammelte
Werke (GW 20).

Source: the **Digitale Hegel-Edition** by Giuliano Infantino
(<https://www.hegeledition.com>, database CC BY 4.0) — the DTA-Basisformat
TEI transcription `GW20.xml`, with GW pagination. The edition's
`work-gw-20.js` is consulted only as an oracle for line-end hyphens (its
paragraph text is already dehyphenated); it is not an independent witness.
Both files live gitignored in `raw/`.

## Layers

**The two MD layers are the editorial surface.** Edit them by hand, in both
layers together; they are never regenerated. The converter and the tables
below only record how the layers were bootstrapped from the TEI, and the
converter refuses to write into a directory that already holds Markdown.

- `md_reviewed/` — the GW text as captured: spelling, punctuation, `[…]`
  supplements and print errors kept. Generated by
  `cargo run -p hegel4_dtabf_to_md`; the converter refuses to emit on
  anything it was not written to handle (bootstrap only, see above). Line-end hyphens are settled from
  the JSON oracle, or from `hyphen_rulings.tsv` where the JSON cannot.
- `md_modernized/` — the reading text, spelling-modernized word by word from
  `modernize_rulings.tsv`
  (`cargo run -p hegel4_dtabf_to_md -- --layer modernized`). Seeded from
  hegel2 and hegel3 (same author, era and orthography); the `source` column
  says where each ruling came from and `certainty` flags the `uncertain`
  ones. A pre-reform trace (`ey`, `ſ`) the table does not rule on stops the
  run.

## Markup

Every § is a `##` heading line carrying its `{{ N }}` marker
(`## {{ 20 }} §. 20.`). A Remark (Anmerkung) run is a `::: remark` … `:::`
fence, its first paragraph opened by `{{ N A }}` (a later run in the same § by `{{ N A2 }}` … `{{ N A9 }}`); each paragraph inside is
its own `remark` block. GW page starts are `{{{ 20.N }}}`. Footnotes are
`[^N]`, numbered per node file, definitions at the end of the node file.

## Page-crossing paragraphs

Where the XML closes a `<p>` at a page break and opens another,
`page_joins.tsv` decides (`gw_page`, `decision` = `join`|`keep`, `certainty`,
`note`). The converter joins only `join` rows. A shape test (first part ends
`-`, `,`, `;` or a letter, second starts lowercase) merely detects: a
boundary it flags with no row, or a row matching no split boundary, stops the
run.

## Indented runs

`indent_runs.tsv` (`section`, `first`, `last`, `note`) names main-text
paragraphs of one § (counted from 1, after page joins) that are one
paragraph of indented items; the converter emits them as `+ ` lines. A row
that matches no run stops the run (§ 76: the numbered list 1)-3)).

## Section headings

A `## {{ N }} §. N.` heading that would close a node file while its text
follows the next node heading is moved to open that node (§§ 330-333). A page
marker the moved heading carried passes to the node heading.

## What is included

The whole text from the Vorrede zur zweiten Ausgabe to the closing
Aristotle quotation (178 nodes, 577 §§, 20 footnotes).

**Excluded**: the title page, the Inhalts-Anzeige (not in the source XML),
and the half-titles "II. NATURPHILOSOPHIE" and "III. PHILOSOPHIE DES GEISTES"
(they duplicate the Theil headings that follow them). The 671 `#vr`
milestones (unnumbered leaf changes of the 1830 print) and 5 vertical spaces
are dropped; the 13 `<foreign>` elements are kept as plain text.

`review_queue.md` lists what still needs a human decision.
